# Todo List App

A simple and responsive Todo List built with **HTML**, **CSS**, **JavaScript**, and **Bootstrap**.  
This project allows users to add and remove tasks easily in a clean and user-friendly interface.

---

## Technologies & Tools

- HTML
- CSS
- JavaScript 
- Bootstrap

## Getting Started (Local Setup)

1. Clone the repository:

```bash
git clone https://github.com/zeinabhoma/myTodoList.git
 ```

2. Navigate to the project folder and install dependencies:

```bash
cd myTodoList
```

3. Open the index.html file in your browser

---

##  Features

- Add and remove todo items
- Fully responsive design using Bootstrap
- Simple and intuitive UI
- Built with pure JavaScript, no external libraries
